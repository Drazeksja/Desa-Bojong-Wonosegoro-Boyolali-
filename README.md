# Website Pemerintah Kabupaten Demak

Frontend resmi Pemerintah Kabupaten Demak yang modern, responsif, dan informatif.

## Fitur Utama
- **Desain Modern & Profesional**: Menggunakan skema warna resmi (Biru Tua & Emas).
- **Layanan Publik**: Akses cepat ke layanan kependudukan, perizinan, dan kesehatan.
- **Transparansi**: Akses dokumen APBD, SAKIP, dan Laporan Keuangan.
- **Responsif**: Tampilan optimal di Mobile, Tablet, dan Desktop.

## Teknologi
- **Next.js 14**: Framework React untuk performa tinggi dan SEO.
- **TypeScript**: Kode yang lebih aman dan terstruktur.
- **CSS Modules / Variables**: Desain sistem tanpa ketergantungan framework CSS berat.
- **Lucide React**: Ikon modern dan ringan.

## Cara Menjalankan

1.  Pastikan Node.js terinstal.
2.  Instal dependensi:
    ```bash
    npm install
    ```
3.  Jalankan server development:
    ```bash
    npm run dev
    ```
4.  Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

## Struktur Project
- `src/app/page.tsx`: Halaman utama (Landing Page).
- `src/app/globals.css`: Sistem desain, variabel warna, dan utilitas CSS.
- `src/app/layout.tsx`: Layout utama dan font configuration.
